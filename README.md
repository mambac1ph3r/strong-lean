# Strong & Lean Journal

1. Create a new public repository on github.com (e.g. `strong-lean`).
2. Click **Add file → Upload files**, drag in every file from this folder, click **Commit changes**.
3. Go to **Settings → Pages**, under *Build and deployment* choose **Deploy from a branch**, branch `main`, folder `/ (root)`, click **Save**.
4. After about a minute your app is live at `https://<your-username>.github.io/strong-lean/`.
5. Open that link in Safari (iPhone) → Share → **Add to Home Screen**. On Android, Chrome shows an **Install app** prompt.

Entries are stored on the device. Use **Plan → Backup** to copy them out.
